# Структура проекта Chimera

## Компоненты

- `LandingPage` — главная страница
- `HeroChimera` — hero-секция с CTA и мок-апом
- `Navigation` — навигация
- `FeaturesSection` — блок возможностей
- `BenefitsSection` — преимущества
- `VideoSection` — секция с видео
- `CTASection` — призыв к действию
- `PartnerLogos` — лента логотипов LLM
- `LoginModal`, `RegisterModal` — модальные окна авторизации
- `GlitchText` — анимированный текст

## Основные модули

- `constants/` — контент, навигация, конфиги
- `hooks/` — useHideOnScroll, useRevealOnScroll
- `utils/` — generateSectionStars, getYouTubeEmbedUrl
- `api/` — auth API
