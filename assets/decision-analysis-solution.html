Задание 1 — Выбор инвестиционного проекта

Исходные данные

Параметр Проект 1 Проект 2
Вероятность 0,1 0,7 0,2 0,2 0,4 0,4
Наличные поступления, млн руб. 30 80 50 -20 100 80

1. Математическое ожидание

Проект 1:

E(X₁) = 0,1×30 + 0,7×80 + 0,2×50 = 3 + 56 + 10 = 69 млн руб.

Проект 2:

E(X₂) = 0,2×(-20) + 0,4×100 + 0,4×80 = -4 + 40 + 32 = 68 млн руб.

2. Среднеквадратическое отклонение

σ = √[Σ pᵢ × (xᵢ − E(X))²]

Проект 1:

σ₁² = 0,1×(30−69)² + 0,7×(80−69)² + 0,2×(50−69)²
σ₁² = 0,1×1521 + 0,7×121 + 0,2×361 = 152,1 + 84,7 + 72,2 = 309
σ₁ = √309 ≈ 17,58 млн руб.

Проект 2:

σ₂² = 0,2×(-20−68)² + 0,4×(100−68)² + 0,4×(80−68)²
σ₂² = 0,2×7744 + 0,4×1024 + 0,4×144 = 1548,8 + 409,6 + 57,6 = 2016
σ₂ = √2016 ≈ 44,90 млн руб.

3. Коэффициент вариации

CV = (σ / E(X)) × 100%

CV₁ = (17,58 / 69) × 100% ≈ 25,5%
CV₂ = (44,90 / 68) × 100% ≈ 66,0%
